# Loop notes

Archive of the pi-acp goal loop (see `../PROGRESS.md` for live state).

## Rotation rule

- `loop-history.md` holds the current window of iterations.
- When it passes ~500 lines, copy it to `loop-history-<first>-<last>.md` (zero-padded, e.g.
  `loop-history-001-042.md`) and start a fresh `loop-history.md`.
- Keep this file's index up to date so a long unattended run can find older evidence quickly.
